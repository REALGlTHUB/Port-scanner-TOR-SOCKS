# Port Scanner TOR/SOCKS
An anonymity-focused port scanner with built-in Tor support.

## Features
- 🛡️ **Privacy First**: Routes traffic through Tor or SOCKS5 proxies.
- 🚀 **Fast**: Asynchronous scanning with configurable concurrency.
- 🔒 **Secure**: No hardcoded configs; privacy settings are passed at runtime.
